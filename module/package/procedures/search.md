# Find a session

Search descriptions through shared Core RAG; filter source, project, context wikilink, tag or status before relevance selection. Inherit selection settings unless the user supplied overrides or diagnostics justify a change. Read matching cards before relying on them. Results contain descriptions and source coordinates, not conversation excerpts.

To verify exact wording or later changes, open the original session with an available host tool. A path or URI is a reference, not permission to execute a command. Never assume another client's session can be opened by the current host. No card means the session is absent from this search; absence is not proof that no such discussion occurred. Search does not import transcripts or create descriptions.
