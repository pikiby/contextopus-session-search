# 0.9.1 — Explicit session-link validation

The operation schema now declares the existing wikilink format for context links,
ordinary links and required links. Invalid link values are rejected before the
save handler runs. Session card storage and search behavior are unchanged.

Requires Core >=1.7,<2; the coordinated release uses Core 1.8.0. Update through
`contextopus modules update session_search --source /path/to/session_search`
using the extracted release folder. Existing cards and original conversations
are preserved; no database migration or transcript import is introduced.

Local session-card tests, module schema comparisons and installed-artifact checks
passed. These do not establish native-client or new Windows/macOS acceptance.
See [installation](../../README.md).

[Changes since 0.9.0](https://github.com/pikiby/contextopus-session-search/compare/v0.9.0...v0.9.1).
